# Task3 Library Management

This project is a simple Java application that models a small library system. It includes the ability to represent books, users, and the core library operations needed to manage lending and returns.

## What it does

- Defines `Book` objects with title, author, ISBN, and availability status
- Defines `User` objects to represent people borrowing books
- Implements `Library` behavior for checking books in and out
- Contains a `Main` class to demonstrate how the system works

## Why it exists

The goal of this project is to practice object-oriented design in Java. It demonstrates how classes can work together to model a real-world system in a straightforward way.

## How to run

1. Compile the Java classes using your Java compiler
2. Run the `Main` class

Example:

```bash
javac *.java
java Main
```
