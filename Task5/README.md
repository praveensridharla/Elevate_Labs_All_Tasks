# Task5 Java Account Demo

This project demonstrates a basic bank account model in Java. It includes:

- `Account.java` — tracks owner, balance, and transaction history
- `Main.java` — creates an account, performs deposits and withdrawals, and prints the history

## How to run

1. Compile both files:
   `javac Account.java Main.java`
2. Run the program:
   `java Main`

The output shows deposit and withdrawal operations, including an insufficient funds message, followed by the account statement.
