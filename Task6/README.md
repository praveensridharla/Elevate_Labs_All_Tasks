# ToDoApp

A simple Java command-line ToDo application.

## Build and Run

Compile:
```bash
javac ToDoApp.java
```

Run:
```bash
java ToDoApp
```

## Notes

- This project contains a single Java source file: `ToDoApp.java`.
- Update the code or add features as needed.
